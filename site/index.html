How it works

From an approved issue to a contribution you can review

1

Choose a task

The owner picks a GitHub issue, sets a time budget and checks, then approves a donor

The donor knows the scope before spending compute

2

Run it locally

The donor runs Tokate with their own Codex account and the project’s build tools

The AI works in a separate checkout on the donor’s machine

3

Review the result

Tokate runs the checks and opens a draft pull request when they pass

The owner reviews the changes and decides what to merge

Your accounts stay yours, and the owner keeps the final say
